# Oversay Homebrew tap

Install [Oversay](https://oversay.app) on a Mac (Apple silicon or Intel, macOS 11 or later):

```bash
brew install oversayapp/tap/oversay
```

The app updates itself; `brew upgrade` also picks up new releases. The cask is updated by the release job in [oversayapp/oversay](https://github.com/oversayapp/oversay) (see its `docs/releasing.md`).
